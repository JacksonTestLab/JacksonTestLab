## 🙋🏻‍♂️ Sobre mim

Sou **Jackson, Analista de QA**, em constante desenvolvimento profissional na área de Quality Assurance, com foco em qualidade de software, testes funcionais, automação de testes, validação de APIs e banco de dados.

Meu objetivo é identificar falhas, investigar comportamentos inesperados e contribuir para a entrega de sistemas mais estáveis e confiáveis.

Tenho desenvolvido projetos práticos envolvendo:

- Planejamento e execução de testes de software.
- Elaboração e documentação de cenários de teste.
- Testes de API e validação de respostas HTTP.
- Automação de testes web.
- Consultas SQL e validação de dados diretamente no banco.
- Investigação, registro e documentação de bugs.
- Organização de evidências e relatórios de execução.
- Utilização de Git e GitHub para versionamento de projetos.

Acredito que qualidade vai além de encontrar bugs: envolve compreender requisitos, antecipar riscos e garantir que o software entregue o comportamento esperado.
